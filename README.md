# branding.alexmerced.com

> Build an Unignorable Personal Brand on Proof of Work.

Official site for Alex Merced's perspective on personal branding, career sovereignty, learning in public, and the companion book **Reputation as Code**.

## Stack
- [Astro 7](https://astro.build)
- Modern CSS variables and semantic design tokens
- Markdown blog collection (`src/content/blog/`)
- Client-side interactive Brand Audit tool (`src/pages/audit.astro`)
- Amazon book portal (`src/pages/book.astro`)
- AI / Agent discovery via `/llms.txt`

## Development
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```
